# Caixa de Partículas

Uma animação interativa de partículas feita com HTML5 Canvas e JavaScript puro (sem dependências).

## Como rodar

Basta abrir o arquivo [index.html](index.html) em qualquer navegador moderno — não precisa de servidor ou build.

## Controles

- **Mover o mouse**: solta um rastro de partículas.
- **Clicar**: causa uma explosão de partículas no ponto clicado.
- **Segurar o clique**: atrai ou repele as partículas próximas, dependendo do modo selecionado.
- **Atrair / Repelir / Livre**: alterna o comportamento das partículas ao segurar o clique.
- **Seletor de cor**: define a cor base das partículas.
- **Rastro**: controla o quanto o rastro das partículas persiste na tela.
- **Limpar**: reseta a tela e remove todas as partículas.
